# Hyouka: Neon Frontier

Android-only Godot 4.7.2 .NET 3D game build.

## Production-scale systems

- Three-stage campaign with auto-save and continue flow.
- Third-person procedural 3D character with procedural walk, idle, weapon and thruster animation.
- Combat: blaster projectiles, hit VFX, muzzle flash, enemy ranged attacks and boss combat.
- Enemy AI archetypes: drone, striker and juggernaut, plus Warden Prime boss behavior.
- Large 76m arena with modular obstacle placement, landmarks, sector tinting and distance-based visual LOD/culling.
- Pickups for health and energy.
- Generated runtime audio for shots, impacts, damage, boost, pickups, explosions and stage transitions.
- Performance HUD with FPS/frame-time monitoring and automatic quality reduction when frame rate drops.
- Dynamic lighting/shadows and particle quality tiers for Android performance.
- Fullscreen Android presentation with responsive HUD and touch controls.
- Main menu, continue/new run, pause, game-over and campaign-complete flows.

This remains an asset-free production-scale gameplay foundation rather than a literal studio AAA content package: no copyrighted third-party character/animation/audio assets are bundled. Characters, animations, VFX and audio are generated by Godot at runtime.

Distribution target: Android debug APK. No HTML game implementation is included.
