# Hyouka: Neon Frontier

Android-only Godot 4.7.2 .NET 3D game build.

## AAA-style mobile presentation pipeline

- Real game-ready GLB character assets with authored materials.
- Real environment GLB hero assets layered into the procedural combat maps.
- PBR-capable materials, filmic tonemapping and controlled directional shadows.
- Enemy GLB animation playback plus procedural movement/idle motion.
- Touch-first third-person controls with a camera-look gesture and a touch-origin-relative virtual joystick.
- Three-stage campaign with auto-save and continue flow.
- Combat gameplay, enemy AI archetypes, boss behavior, hit VFX, pickups and generated runtime audio.
- Large 76m arenas with modular obstacle placement, landmarks, sector themes and distance-based visual LOD/culling.
- FPS/frame-time HUD with automatic quality reduction for Android.
- Fullscreen landscape Android presentation with responsive HUD and touch controls.

The visual pipeline uses CC0 assets rather than copyrighted third-party content. Game collisions and gameplay behavior are still generated by Godot at runtime so the visual assets do not dictate the game physics.

Distribution target: Android debug APK. No HTML game implementation is included.
